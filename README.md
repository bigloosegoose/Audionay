# Audionay

Basically a player , retro aesthetic kinda sorta

## What is it actually?

This is a web player you can use to add your songs and listen to without having to have a dedicated app installed. It even stores the songs in browser storage so you don't have to add them back in your next listening session. Can upload multiple files at once. Tons of improvement to be made yet.

## Features:

- Win XP Aesthetic
- Window Scaling
- A clock
- A playlist to which you can add songs and of course remove them too
- Basic controls like forward, previous, play, pause, loop and auto(play songs in a queue)

## Features I might add:

- An Equaliser

## Tech Stack:
As Audionay is a static website which stores uploaded songs in the local browser storage, it just uses:
- HTML
- CSS
- JS
